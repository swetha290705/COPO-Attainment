# CO-PO Attainment Tracking System (Frontend)

## Overview

The CO-PO Attainment Tracking System is a frontend web application developed to simplify the management and visualization of Course Outcome (CO) and Program Outcome (PO) attainment in educational institutions. The project provides an intuitive user interface for administrators and faculty members to manage academic data and monitor outcome-based education processes.

The current version focuses on frontend development and includes responsive interfaces for teacher management, subject management, class management, teacher allocation, CO-PO mapping, attainment dashboards, and reporting modules. The application is designed to provide a seamless user experience while serving as a scalable foundation for future backend integration and database connectivity.
